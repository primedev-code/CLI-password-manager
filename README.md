# 🔐 Password Manager

Простой консольный менеджер паролей на Python. Защищён мастер-паролем, хранит пароли от сайтов и сервисов в локальном файле и управляется через текстовое меню в терминале.

> ⚠️ **Учебный проект.** Данные хранятся в открытом виде. Не используйте его для реальных паролей (подробности в разделе [Безопасность](#безопасность)).

## Возможности

- Вход по мастер-паролю (ввод скрыт через `getpass`)
- Добавление пароля для сайта или сервиса
- Просмотр сохранённых паролей
- Изменение пароля от сайта или сервиса
- Очистка всей базы паролей
- Автоматическое создание файлов данных при первом запуске

## Требования

- Python 3.8+
- Только стандартная библиотека (`getpass`, `pathlib`), внешние зависимости не нужны

## Запуск

```bash
git clone <ссылка-на-репозиторий>
cd passwordmanager
python password_manager.py
```

При первом запуске программа создаст два файла рядом со скриптом:

| Файл | Назначение |
|---|---|
| `masterpassword.txt` | Мастер-пароль. По умолчанию `admin` |
| `passwords.txt` | Сохранённые пароли (изначально пустой) |

**После первого запуска замените мастер-пароль:** откройте `masterpassword.txt` и впишите свой.

## Использование

После ввода верного мастер-пароля открывается меню:

```
1 - Добавить пароль
2 - Посмотреть сохраненный пароль
3 - Изменить пароль от сайта/сервиса
4 - Очистить базу паролей
5 - Выйти
```

Введите номер пункта и следуйте подсказкам на экране.

## Безопасность

Проект написан для обучения и сознательно упрощён:

- мастер-пароль и пароли хранятся **в открытом тексте**;
- нет шифрования и хеширования;
- мастер-пароль по умолчанию — `admin`.

Не коммитьте `masterpassword.txt` и `passwords.txt`: они добавлены в `.gitignore`.
